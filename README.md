# SkillCam Mobile Test

Zero-cost iPhone Safari prototype for validating badminton Smash measurements.

## Workflow

Player video → MediaPipe pose analysis in Safari → factual/proxy metrics → local IndexedDB session → blind coach review → system reveal → agreement dashboard.

## Privacy

Prototype sessions and selected video clips are stored locally in Safari on the iPhone used for the test. They are not uploaded by this prototype.

The browser downloads the MediaPipe JavaScript/model assets from external CDNs when analysis starts.

## Product boundary

This is a Skill Analyzer validation prototype. It does not claim professional coaching, correct/incorrect technique, shuttle speed, exact racket angle, or injury-prevention advice.
